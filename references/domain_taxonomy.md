# 模型技术类型归类速查

用于在步骤 0 快速判断资料所属技术类型，从而选定挖掘切入面与撰写侧重。

| 类型 | 典型关键词 | 优先切入面 | 撰写侧重 | 客体绑定要点 |
|------|------------|------------|----------|--------------|
| **T1 视觉检测/识别/分割** | 目标检测、语义分割、实例分割、缺陷检测、OCR、医学影像 | B（结构）、A（数据增强）、G（后处理） | 输入为图像像素数据，输出为缺陷位置/类别，驱动剔除/报警 | 强调图像数据的技术含义与检测结果驱动的产线动作 |
| **T2 时序预测/故障诊断** | 振动信号、RUL、SOC/SOH、载荷预测、异常检测、PHM | B、C（损失）、H（工况耦合） | 输入为传感时序，输出为状态量/剩余寿命，驱动维护决策 | 绑定物理设备状态与维护/停机控制 |
| **T3 自然语言处理/知识处理** | 文本分类、抽取、检索、问答、知识图谱、大模型 | B、D（训练策略）、E（部署） | 输入为技术文档/工单/标准文本，输出为结构化技术信息 | **客体风险高**：必须绑定到具体工业文本处理与 downstream 技术动作（如生成检修方案、驱动设备配置） |
| **T4 强化学习/控制决策** | 策略网络、奖励函数、调度、路径规划、能量管理 | F（优化）、H（闭环） | 状态/动作/奖励需有物理含义，输出直接作用于被控对象 | 状态空间与奖励绑定设备物理量，输出为控制量 |
| **T5 生成/重建/超分辨** | GAN、扩散、自编码器、图像重建、缺失数据补全 | C（损失）、B、A | 输入为退化/缺失的工业数据，输出为高质量复原数据用于后续检测 | 复原数据在检测/测量中的可用性提升 |
| **T6 模型压缩与部署** | 剪枝、量化、蒸馏、NAS、边缘推理、算子优化 | E、D | 强调与具体硬件平台、算力/内存/功耗约束的耦合 | 以硬件资源指标与可部署性作为技术效果 |
| **T7 多模态融合** | 图像+点云、视觉+力觉、声+振、跨模态 | A、B、H | 强调模态间互补与对齐、缺失容错 | 绑定多传感器物理量与融合后的检测/控制性能 |
| **T8 联邦/隐私/分布式** | 联邦学习、边缘协同、隐私计算 | D、E | 强调通信开销、数据不出域下的性能 | 绑定工业现场多站点部署与带宽约束 |
| **T9 图神经网络/关系建模** | GNN、拓扑、设备关联、管网、电路 | B、C | 图结构来自物理拓扑（管网/电路/传动链），非抽象关系 | 强调图节点的物理实体含义 |
| **T10 物理信息/机理融合** | PINN、机理-数据混合、数字孪生 | C（约束损失）、H | 强调物理方程约束与数据驱动结合 | 物理约束直接提升工程可解释性与外推能力 |

## 归类后的动作

1. 确定类型后，到 `references/innovation_playbook.md` 中优先扫描对应切入面。
2. 记录该类型的**典型评测指标**（用于技术效果量化）：
   - T1：mAP / IoU / AP50 / 漏检率 / 误检率 / FPS
   - T2：RMSE / MAE / 准确率 / 早期预警提前量 / 误报率
   - T3：Precision / Recall / F1 / 抽取准确率 / 人工复核时长
   - T4：累计奖励 / 能耗下降 / 收敛步数 / 控制误差
   - T5：PSNR / SSIM / FID / 下游检测精度增益
   - T6：参数量 / FLOPs / 时延 / 显存 / 功耗 / 精度损失
   - T7：融合增益 / 缺失模态下性能保持率
   - T8：通信轮次 / 上行数据量 / 相对集中训练的精度差
   - T9：节点分类准确率 / 链路预测 AUC
   - T10：物理约束违反率 / 外推工况误差
3. 将类型与指标写入技术要素表，供步骤 3–5 使用。
