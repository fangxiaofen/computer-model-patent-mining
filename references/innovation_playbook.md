# 计算机模型类发明专利 · 创新点挖掘套路库

> 用法：挖掘阶段逐面扫描，对每个切入点自问「背景技术资料里是否已有对应设计？若无，且能解决一个已登记痛点，即为候选发明点」。
> 每个切入点给出：**常见缺陷 → 可主张的技术手段 → 可量化的技术效果口径**。

## 切入面 A｜数据层面

| # | 常见缺陷 | 可主张技术手段 | 效果口径 |
|---|----------|----------------|----------|
| A1 | 标注样本稀缺 / 标注成本高 | 半监督伪标签迭代、置信度筛选 + 一致性正则、主动学习挑选高价值样本 | 标注量减少 X% 下精度保持 Y% |
| A2 | 类别/工况不均衡 | 动态重采样、类别自适应加权、难例挖掘（在线/离线） | 少数类召回率提升、G-mean 提升 |
| A3 | 标注噪声 / 标签错误 | 噪声标签校正、协同教学（co-teaching）、标签平滑、噪声鲁棒损失 | 20% 噪声率下精度下降幅度收窄 |
| A4 | 多源异构数据难融合 | 模态对齐、跨模态注意力、缺失模态补全、特征级/决策级融合策略 | 融合后 vs 单模态精度提升 |
| A5 | 数据分布漂移 | 领域自适应、分布对齐（MMD/CORAL）、测试时自适应归一化 | 跨工况性能下降幅度收窄 |
| A6 | 某类样本天然难学 | 课程学习（由易到难）、难度度量与调度策略 | 收敛轮次减少、最终精度提升 |
| A7 | 时序数据长程依赖难捕获 | 分段采样、多尺度时序切片、时序增强（抖动/遮蔽/混合） | 长序列任务 F1 提升 |

## 组合型发明点的创造论证要点

单项常规时，主张 A+B（或 A+B+C）的组合：
1. 明确组合的**协同机理**（为什么组合后产生 1+1 > 2）；
2. 给出**消融实验**支撑（去 A、去 B、去 A+B 的对比）；
3. 论证**非显而易见**：现有技术中 A、B 各自用于解决不同问题，无结合启示，或结合后需克服技术偏见；
4. 效果用组合 vs 最优单项的**增量**表述。
