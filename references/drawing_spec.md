# 专利说明书附图 · 制图规范与模板

## 1. 通用规范（《专利审查指南》第一部分第一章 4.3 附图相关要求）

1. **线条**：用绘图工具和黑色墨水绘制，线条均匀清晰、足够深，**不得着色、不得用照片**；不得用工程蓝图。
2. **标注**：图中**除必需的词语外，不含有其他注释**；注释应使用中文（外文缩写如 CNN、ReLU 属必要技术术语可用）。
3. **编号**：附图标记用**阿拉伯数字**，同一部件在几幅图中出现须用**同一标记**；标记按图从左到右、从上到下顺序编排。
4. **尺寸**：缩小到三分之二仍能清晰分辨所有细节；最小线宽 ≥ 0.1 mm；字体高度 ≥ 1.8 mm（缩放后）。
5. **多图**：用阿拉伯数字顺序编号「图 1、图 2……」，一幅图尽量一页；同一图分多页时用「图 3A / 图 3B」并画出接续关系。
6. **框图/流程图**属允许的示意图形式，允许用方框、箭头表示组成与流向。
7. 图中不得出现：人名、商标、商业宣传语、与技术方案无关的装饰。

## 2. 图 1 系统框架图规范

### 2.1 图形元素约定
| 元素 | 图形 | 用途 |
|------|------|------|
| 功能模块 | 矩形实线框 | 模型/系统模块 |
| [创新] 模块 | 矩形**粗实线框 / 灰底填充** | 本专利核心创新模块，视觉区分 |
| 外部实体（传感器/数据库/执行机构） | 圆角矩形或圆柱 | 系统边界外 |
| 数据存储 | 圆柱 | 数据库、模型库、样本库 |
| 数据流 | 实线箭头 + 线上标注数据形态 | 主要数据通路 |
| 控制信号 / 反馈 | **虚线箭头** | 参数下发、反馈校正 |
| 训练态-推理态参数同步 | **双线箭头** | 权重同步 |
| 子系统分组 | 大虚线外框 + 层名 | 分层架构 |

### 2.2 布局建议
- A4 纵向，**自上而下分层**（推荐）或自左而右；
- 每列/层对齐，箭头不交叉（不可避免时用跨线弧）；
- 模块数控制在 6–12 个，过多时合并为子系统；
- 右下角留「图 1」图号标注位置。

## 3. 图 2 核心方法流程图规范

### 3.1 图形元素约定
| 元素 | 图形 |
|------|------|
| 开始 / 结束 | 圆角矩形（或椭圆） |
| 处理 / 计算步骤 | 矩形 |
| 判断 / 分支 | 菱形（两路出口标「是」「否」） |
| 数据输入 / 输出 | 平行四边形 |
| 数据存储 | 圆柱 |

### 3.2 结构要求
- 必须覆盖五段：**数据准备 S 段 / 模型训练 S 段 / 特征提取 S 段 / 推理预测 S 段 / 优化校正 S 段**；
- 判断节点必须**两路都有去向**，形成闭环或终止；
- 步骤编号 S1、S2…… 连续，分支回跳标注回到哪个编号；
- 每个步骤框内文字 ≤ 20 字，超长部分写入说明书正文；
- 每个步骤标注对应的**必要技术特征编号**（便于审查员对照）。

### 3.3 输出清单模板
```
### 图 2 核心方法流程图

**流程主线**
S1 获取原始工况数据
 → S2 数据清洗与归一化
 → S3 时频变换与数据增强
 → S4 构建训练样本集并划分
 → S5 初始化网络参数
 → S6 前向计算，得到多尺度特征
 → S7 计算复合损失 L = αL_cls + βL_dis + γL_reg
 → S8 反向传播更新参数
 → S9{验证集指标连续 E 轮未提升？}
      ├─ 否 → 回到 S6
      └─ 是 → S10 保存最优权重
 → S11 输入待检测数据，执行特征提取与加权融合
 → S12 输出故障类型与置信度
 → S13{置信度 ≥ 阈值 τ？}
      ├─ 是 → S15 输出并执行控制
      └─ 否 → S14 触发重采样/多视角复核 → 回到 S11
 → S16 结束

**节点表**
| 编号 | 节点类型 | 节点内容 | 对应必要技术特征 | 说明书段落 |
| S1 | 平行四边形 | 获取原始工况数据 | 特征1 | 2.5 |
| S9 | 菱形 | 是否连续 E 轮未提升 | 特征7 | 2.7 |
```

## 4. 附图说明文字模板（可直接写入说明书）

```
附图说明
图 1 为本发明实施例中基于多尺度注意力加权卷积神经网络的轴承故障识别系统的框架示意图；
图 2 为本发明实施例中该方法的流程示意图；
图 3 为本发明实施例中多尺度融合模块的内部结构示意图。

图中：1-数据采集模块；2-时频变换模块；3-特征提取骨干网络；4-多尺度融合模块；5-注意力加权模块；6-故障分类输出模块；7-置信度判别与反馈校正模块；8-云侧模型管理模块。
```

撰写要求：
- 一句一图，以「图 X 为本发明实施例中……的……示意图；」句式；
- 附图说明**只列标记与名称**，不写功能解释、不写效果评价；
- 图中未出现的标记不列入，列入的标记必须在图中出现。

## 5. 交付前的图-文一致性核对

- [ ] 图中标记编号 1..N 连续、无重复、无跳号
- [ ] 每个标记在附图说明中均有对应条目
- [ ] 正文中「模块名 + 标记」与图中完全一致（如"多尺度融合模块 4"）
- [ ] 流程图的每个步骤都能在正文技术方案中找到对应描述
- [ ] 创新模块已在图 1 中视觉区分（粗框/填充）
- [ ] 无照片、无彩色、无商标、无宣传文字
