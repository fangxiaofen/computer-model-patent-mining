# 步骤 4｜技术方案（含全部必要技术特征，详细可落地）

**目标**：写出审查员和本领域技术人员看完即可实施、且**删去任一必要技术特征即无法解决技术问题**的完整技术方案。

## 4.1 必备八要素（缺一不可，按顺序成章）

| # | 章节 | 必须写清的内容 |
|---|------|----------------|
| 1 | **系统整体架构** | 系统由哪几级/哪几层构成（如：数据采集层 → 预处理层 → 模型推理层 → 决策输出层 → 反馈校正层），各层之间的连接关系与部署位置 |
| 2 | **模型核心模块组成** | 逐模块命名 + 功能定位 + 输入输出张量/数据形态（维度、通道、尺度） |
| 3 | **各模块执行步骤** | 每一步"接收 X → 执行 Y 操作 → 输出 Z"，写明算子/运算的具体形式 |
| 4 | **算法优化逻辑** | 创新点所在：改进的计算式、加权策略、融合规则、门控/注意力机制、搜索或选择逻辑 |
| 5 | **数据处理流程** | 采集 → 清洗 → 标注 → 增强 → 归一化 → 划分 → 迭代喂入的完整链路与格式约定 |
| 6 | **参数配置规则** | 关键超参的取值或取值区间 + **取值依据/自适应规则**（不得只给一个孤立数字） |
| 7 | **模型训练与推理方式** | 训练：损失构成与权重、优化器、学习率策略、批大小、轮次、早停/验证策略；推理：输入预处理一致性、批处理、加速手段、输出解码 |
| 8 | **交互联动关系** | 模块间、模型与硬件/传感器/执行机构之间、训练态与推理态之间的联动与反馈机制 |

## 4.2 必要技术特征的标注规范

- 以「**必要技术特征 N：……**」为段落起始并加粗，N 从 1 连续编号，建议 5–9 条。
- 每条必要技术特征只写**一个**不可分割的技术手段单元；若可再拆，则拆分。
- 每条末尾用括号注明解决的技术问题编号，如「（解决 P2-1）」。
- 从属/优选的技术手段单独用「**优选特征 N-a：**」标注，不得混入必要技术特征。

## 4.3 公知与创新分离（在文中显式标注）

在每个模块段落末尾或段落内，用简短标注区分：
- `[公知]`：本领域常规手段（如 CNN 卷积、BatchNorm、Adam）
- `[创新]`：本专利独有设计，直接对应核心发明点 C1 或从属增强点 D1/D2/D3

## 4.4 专利化语言要求

1. **算法式必须写成可实施的运算描述**，禁止只写"通过神经网络提取特征"。正确范式：
   > 将特征图 F∈R^(C×H×W) 分别经全局平均池化与全局最大池化，得到两个 C 维向量；将两向量拼接后输入含一层隐藏层的多层感知机，隐藏层维度为 C/r（r 为压缩比，取 16），经 Sigmoid 激活得到通道权重向量 w∈R^C；将 w 与 F 按通道逐元素相乘，得到加权特征图 F′。
2. **参数要有规则**：如"阈值 τ 依据验证集上 F1 最大处确定"或"τ∈[0.3,0.7]，优选 0.5"。
3. **避免纯数学抽象**：每一次数学运算都要绑定其**技术含义**（如"该注意力权重表征振动信号中故障冲击分量的贡献度"）。
4. **客体绑定**：明确输入为**外部技术数据**，输出用于**技术控制/检测/诊断/预测**。
5. **术语统一**：全篇同一概念用同一术语，与附图标记一致；英文缩写首次出现给中文全称。
6. 不使用"本发明可以……"式的推测罗列；使用"所述模块配置为……""所述步骤具体包括……"。
