# 步骤 6｜专利说明书附图方案

**目标**：输出可直接交予制图人员的**图 1 系统框架图 + 图 2 核心方法流程图**完整构图说明，以及可直接写入说明书的附图说明文字。

制图规范（线条、标记、字体、编号）见 `references/drawing_spec.md`。

## 6.1 图 1｜系统框架图

必须给出：

1. **整体系统组成**：划分 3–6 个层级/子系统（如 数据采集层、边缘预处理层、模型推理层、决策输出层、反馈校正层、云侧管理模块），每层一个外框。
2. **核心模型模块**：每层内部的具体模块（如 特征提取模块、多尺度融合模块、注意力加权模块、检测头/回归头、模型压缩与量化模块），每模块一个矩形框。
3. **数据流向**：箭头 + 线上标注数据形态（如 `原始振动信号 1×2048`、`特征图 256×32×32`、`故障概率向量 1×N`）。
4. **输入/输出端口**：系统边界上的入口（传感器/数据库/外部系统）与出口（执行机构/报警/显示/上报）。
5. **模块交互关系**：实线 = 数据流；虚线 = 控制信号/反馈/参数下发；双线 = 训练态与推理态的参数同步。
6. **附图标记**：全图按 `1、2、3…` 统一编号（模块用方框标记，部件可细分 `1-1`），与说明书正文术语严格一致。

**输出格式**：

```
### 图 1 系统框架图
**构图布局**（自上而下 / 自左而右，建议画布 A4 纵向）：
- 顶层：…
- 第二层：…
- …

**模块清单与附图标记**
| 标记 | 名称 | 功能 | 输入 | 输出 |
| 1 | 数据采集模块 | … | — | 原始信号 |

**连线与流向**
| 起点 | 终点 | 线型 | 承载内容 |
| 1 | 2 | 实线箭头 | 原始振动信号 1×2048 |

**创新点可视化强调**：以粗框/灰度填充标出 [创新] 模块 `4、6、7`，与 [公知] 模块区分。
```

## 6.2 图 2｜核心方法流程图

按**时间/逻辑顺序**给出完整步骤节点，必须覆盖：模型训练 / 数据处理 / 特征提取 / 推理预测 / 优化校正 五段全流程。

节点类型规范：
- 圆角矩形 = 开始/结束
- 矩形 = 处理/计算步骤
- 菱形 = 判断/分支（是/否两路都要画出）
- 平行四边形 = 数据输入/输出
- 圆柱 = 数据存储

**输出格式**：

```
### 图 2 核心方法流程图
**阶段 A｜数据准备**：S1 → S2 → S3 …
**阶段 B｜模型训练**：S4 → S5 →（判断：验证集指标是否收敛？）→ 否 → 回到 S5；是 → S6
**阶段 C｜特征提取与推理**：S7 → S8 → S9
**阶段 D｜优化校正与反馈**：S10 →（判断：置信度是否低于阈值 τ？）→ 是 → S11 校正 → 输出；否 → 直接输出

**步骤节点表**
| 编号 | 节点类型 | 节点内容 | 对应必要技术特征 | 对应说明书段落 |
| S1 | 平行四边形 | 获取原始工况数据 | 特征1 | 2.5 |
```

分支必须闭环（无死路），判断节点两路均标注去向。

## 6.3 附图说明文字（可直接写入说明书）

输出标准段落：

```
图 1 为本发明实施例中 <系统名称> 的系统框架示意图；
图 2 为本发明实施例中 <方法名称> 的流程示意图。

图中：1-数据采集模块；2-预处理模块；3-特征提取模块；4-多尺度融合模块；5-注意力加权模块；6-检测输出模块；7-反馈校正模块；8-云侧模型管理模块。
```

要求：
- 一句一图，以「图 X 为……示意图」句式；
- 附图标记用阿拉伯数字，与图中一致，**不在附图说明中使用功能解释性文字**（解释放正文）；
- 说明中不得出现"如图所示的本发明创新点"等评价性表述。
